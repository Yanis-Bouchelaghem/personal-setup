# personal-setup

Two projects in one repo. Work in the folder that matches the task:

- Extension work: `restitution-extension/`, and read `restitution-extension/CLAUDE.md` first (run npm commands from that folder).
- Machine setup, keybindings, Neovim: `dotfiles/`, and follow `dotfiles/README.md`.
- Installers: `install.ps1` (Windows) and `install.sh` (macOS) at the root. Keep them doing the same steps, keep them small, and update `dotfiles/README.md` when one changes.
