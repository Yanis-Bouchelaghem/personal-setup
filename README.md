# personal-setup

My tools and editor setup, the same on macOS and Windows.

- `restitution-extension/`: the Restitution VS Code extension (see its `docs/DESIGN.md`).
- `dotfiles/`: Neovim, VS Code keybindings and Vimium C, with a README meant to be handed to Claude on a new machine.

On a new machine: clone this repo, open Claude Code in it, and say
"set this machine up from dotfiles/README.md, then install the extension".
