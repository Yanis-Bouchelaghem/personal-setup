Put Vimium C's settings export here as `settings.json`
(Vimium C options > "Export settings"), and restore it on a new machine with
"Import settings". Normally Firefox Sync carries them: turn on "Sync settings
with your current browser account" in Vimium C on every machine.
Mappings with `<m-…>` (Cmd) need `<c-…>` on Windows.
